핵심 요구사항 분석

  • 5개 역할군 통합 UX — 게스트(PC Web/APP), 호스트(Web), 키퍼(APP), 청소관리자(Web), 어드민(Web) 각각의 정보 구조·권한·플로우를 통합한 디자인 시스템 구성
  • 예약·결제·체크인 풀스택 — 지역/날짜/인원 검색·지도, PG 즉시 결제, 정책 기반 자동 취소/환불, QR·도어락 체크인, 리뷰
  • 호스트 비즈니스 운영 — 국세청 API 사업자 확인, PASS 전자서명 위탁계약, 트리거 기반 자동 메시지, 게스트 채팅(자동 번역), AI 수익 최적화 대시보드, 월별 정산 명세서
  • 키퍼/청소관리자 현장 운영 — 초대코드 가입, 가용 일정 등록, 배정 수락/거절, QR/도어락 체크인 지원, 청소 체크리스트 + 사진 업로드, 케어테이커 배정, 지연 모니터링, 완료 검수
  • 어드민 인텔리전스 — 가입/숙소 심사, 예약/결제/청소 통합 모니터링, AI 인텔리전스(케이스 분류·분쟁 처리·사기 탐지), MFA, FCM/이메일/SMS, 실시간 CS 채팅(WebSocket)
  • 기존 DB ETL 마이그레이션 — 회원·예약·결제·리뷰 데이터의 무손실 이관 및 정합성 검증 (공고 명시 핵심 요구)
  • 비기능 요구 — AWS 인프라, WebSocket 실시간 동기화, 개인정보 암호화, PCI DSS Level 1(카드정보 미저장), 키퍼 앱 오프라인/저대역 대응

제안 포인트

  1. 5개 역할군 통합 SaaS 수행 경험 — Harmony Link(6 플랫폼 시니어 케어 멀티역할), EZ-Approve(7 사용자 역할 B2B SaaS) 등 다중 역할 RBAC·통합 어드민 패턴을 그대로 적용 가능합니다.
  2. O2O 예약/현장 운영 경험 — Pilates App에서 수업 예약·강사 배정·출결·결제를 3 플랫폼(iOS/Android/Web)에 동시 출시한 경험으로 게스트 예약·키퍼 배정·청소 검수 워크플로우 설계를 가속합니다.
  3. 외부 인증/결제 연동 풀세트 경험 — Series-B에서 NICE KYC + PASS형 본인인증을, P2P Funding에서 가상계좌(Seyfert/PayGate) + PG 정산을 구현했습니다. 본 건의 PG·PASS·국세청 API 연동에 동일 패턴을 활용합니다.
  4. DB 마이그레이션 무손실 방법론 — 대규모 운영 DB(EZ-Approve 34 엔티티·Series-B 80+ 엔티티) 설계·이관 경험을 기반으로 사전 매핑→스테이징 DB 모의 이관→3단계 정합성 검증→롤백 절차를 표준화하여 적용합니다.
  5. 실시간/WebSocket 협업 설계 — EZ-Approve의 CRDT(Yjs) 기반 실시간 공동편집과 Harmony Link의 알림/케어 로그 동기화 경험으로 실시간 CS 채팅·청소 상태 동기화를 안정적으로 구현합니다.
  6. 단계별 납품 + 장기 파트너십 — 게스트/호스트/키퍼 핵심을 1차 오픈하고 어드민 AI 인텔리전스를 후속 단계로 분할 납품하여 6개월 일정을 안전하게 맞추고, 출시 후 운영·고도화 단계의 장기 파트너십에 적합한 산출물·문서·인수인계 체계를 제공합니다.

PRD (Product Requirements Document)

본 PRD는 클라이언트 제공 기획서를 기반으로 외주사 관점에서 핵심 요구사항을 정리한 외부 검토용 요약본이며, 정식 PRD는 착수 후 클라이언트 PM/기획자와 협업하여 확정합니다.

1. 프로젝트 배경 및 목적

기존 운영 중인 게스트 서비스를 확장하여, 게스트 예약·호스트 운영·키퍼 청소·청소관리자 검수·어드민 모니터링을 하나의 플랫폼에서 처리합니다. 모든 화면 설계와 정책은 클라이언트가 1차 제공하며, 외주사는 구현 가능성·기능 보완·세부 정책 협업과 함께 UI/UX 디자인·Web/App 프론트엔드·백엔드 개발·기존 DB 마이그레이션을 수행합니다.
